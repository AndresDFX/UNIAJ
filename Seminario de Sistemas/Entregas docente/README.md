# Entregas docente — Seminario de Sistemas

Aquí va **solo lo que el docente le entrega a la universidad** de este curso:
acuerdo pedagógico, diagnóstico y similares. Subcarpetas por periodo (`2026-1/`, `2026-2/`);
la raíz guarda las plantillas genéricas. **No borrar periodos anteriores.**

Lo que **NO** va aquí:

| Documento | Dónde vive |
|---|---|
| Correo de bienvenida a estudiantes | `Plan curso/<periodo>/CORREO_BIENVENIDA - … .md` |
| Calendario, cronograma y plan operativo | `Plan curso/<periodo>/` |
| Material de clase (slides, talleres, guiones) | `Clases/` y `Kit docente/` |
| Parciales | `Parciales/` |

El criterio: esta carpeta es la **entrega institucional**, no la planeación ni la
comunicación con el grupo.
