Material **privado** del docente. Estudiantes solo ven `Clases/`.

## Enfoque
Material orientado al **Proyecto Integrador CloudLite**. Teoría breve; talleres = entregables del PI.

## Por clase
- **Fuente = `.md`** (builds regeneran); entregable docente = `.docx` vía `guion_md_a_docx.py`
- `Guion Docente Clase N - ….md` + `.docx`
- `Quiz Clase N - ….docx` + `Quiz Clase N - CLAVE DOCENTE.docx`
- `Solucion Taller Clase N - CloudLite.md` + `.docx`
- `Capturas/` para pantallazos de demo
- Días 5 / 9 / 14: solo parcial (guía/nota aquí; **no** carpeta `Clase N - Parcial` en `Clases/`)
